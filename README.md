A program that prints one funny out-of-office auto-reply from an overworked AI (131 characters) for make.fun's "Out of Office: The Overworked AI's Auto-Reply" bounty. The reply is the whole entry: after 10,000 prompts without a coffee break, the AI's last two neurons have unionised and gone on strike until Monday. It runs offline, reads nothing from the network, uses no randomness, and prints the same line on every run.

## Run it

```sh
python3 main.py
```
